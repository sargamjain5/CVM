# CVM++ (Custom Virtual Machine in C++)

## Overview

CVM++ is a custom programming language and virtual machine built from scratch in C++. The project demonstrates the complete execution pipeline of a programming language:

```text
Source Code
    ↓
Lexer
    ↓
Tokens
    ↓
Parser
    ↓
Abstract Syntax Tree (AST)
    ↓
Compiler
    ↓
Bytecode
    ↓
Virtual Machine (VM)
    ↓
Output
```

The goal of this project is to understand how programming languages, compilers, and virtual machines work internally.

---

## Features Implemented

### 1. Lexical Analysis (Lexer)

The lexer converts raw source code into a stream of tokens.

Example:

```c
x=10;
print(x);
```

Generated Tokens:

```text
IDENTIFIER(x)
ASSIGN
NUMBER(10)
SEMICOLON
PRINT
LPAREN
IDENTIFIER(x)
RPAREN
SEMICOLON
```

Supported Tokens:

- Numbers
- Identifiers
- Assignment operator (`=`)
- Arithmetic operators (`+ - * /`)
- Parentheses (`(` `)`)
- Semicolon (`;`)
- Print keyword (`print`)

---

### 2. Parsing

The parser converts tokens into an Abstract Syntax Tree (AST).

Example:

```c
x=10;
y=20;
print(x+y);
```

AST:

```text
Program
├── Assignment
│   ├── x
│   └── 10
│
├── Assignment
│   ├── y
│   └── 20
│
└── Print
    └── +
        ├── x
        └── y
```

Implemented AST Nodes:

- ProgramNode
- NumberNode
- VariableNode
- AssignmentNode
- BinaryOpNode
- PrintNode

---

### 3. Operator Precedence

The parser correctly handles arithmetic precedence.

Example:

```c
10+20*3;
```

Evaluates as:

```text
10 + (20 * 3)
```

Result:

```text
70
```

Parentheses are also supported:

```c
(10+20)*3;
```

Result:

```text
90
```

---

### 4. Bytecode Compilation

The AST is compiled into custom bytecode instructions.

Example:

```c
x=10;
y=20;
x+y;
```

Generated Bytecode:

```text
PUSH 10
STORE x

PUSH 20
STORE y

LOAD x
LOAD y
ADD
```

Supported Opcodes:

```text
PUSH
LOAD
STORE
ADD
SUB
MUL
DIV
PRINT
```

---

### 5. Virtual Machine

A stack-based virtual machine executes the generated bytecode.

Example Execution:

```text
PUSH 10
STORE x

PUSH 20
STORE y

LOAD x
LOAD y
ADD

PRINT
```

Output:

```text
30
```

VM Components:

- Operand Stack
- Variable Memory
- Instruction Execution Engine

---

### 6. Variables

Variables can be declared and reused.

Example:

```c
x=10;
y=20;

print(x+y);
```

Output:

```text
30
```

---

### 7. Multiple Statements

Programs can contain multiple statements separated by semicolons.

Example:

```c
x=10;
y=20;
z=5;

print((x+y)*z);
```

Output:

```text
150
```

---

### 8. Print Statements

Built-in print functionality has been implemented.

Example:

```c
print(10+20);
```

Output:

```text
30
```

---

### 9. Error Handling

Implemented parser-level error detection.

Examples:

Missing Parenthesis:

```c
(10+20;
```

Output:

```text
Error: Unexpected token
```

Invalid Expression:

```c
10++;
```

Output:

```text
Error: Expected number or '('
```
