# CVM++ 🚀

A custom stack-based programming language, bytecode compiler, and virtual machine built in C++.

CVM++ demonstrates the complete compiler pipeline, from source code to execution through a custom bytecode instruction set and virtual machine.

---

# Overview

```text
Source Code
    ↓
Lexer
    ↓
Tokens
    ↓
Parser
    ↓
Abstract Syntax Tree (AST)
    ↓
Bytecode Compiler
    ↓
Bytecode
    ↓
Virtual Machine
    ↓
Program Output
```

---

# Features

## Variables

```c
x = 10;
y = 20;

print(x);
print(y);
```

## Arithmetic Expressions

```c
print(10 + 5);
print(10 - 5);
print(10 * 5);
print(10 / 5);
```

### Supported Operators

- `+` Addition
- `-` Subtraction
- `*` Multiplication
- `/` Division

## Comparison Operators

```c
print(10 > 5);
print(10 < 5);

print(10 >= 10);
print(10 <= 10);

print(10 == 10);
print(10 != 5);
```

### Supported Operators

- `>`
- `<`
- `>=`
- `<=`
- `==`
- `!=`

## If Statements

```c
if(10 > 5){
    print(100);
}
```

## If-Else Statements

```c
if(10 == 5){
    print(999);
}
else{
    print(111);
}
```

## While Loops

```c
i = 0;

while(i < 5){
    print(i);
    i = i + 1;
}
```

Output:

```text
0
1
2
3
4
```

# Compiler Components

## Lexer

Converts source code into tokens.

Example:

```c
x = 10 + 20;
```

Produces:

```text
IDENTIFIER(x)
ASSIGN
NUMBER(10)
PLUS
NUMBER(20)
SEMICOLON
```

## Parser

Uses Recursive Descent Parsing to generate an AST.

```text
Print
└── BinaryOp(+)
    ├── Number(10)
    └── Number(20)
```

## Bytecode Compiler

Example generated bytecode:

```text
PUSH 10
PUSH 20
ADD
PRINT
```

## Virtual Machine

Supported instructions:

```text
PUSH

LOAD
STORE

ADD
SUB
MUL
DIV

GT
LT
GTE
LTE

EQ
NEQ

JMP
JMP_IF_FALSE

PRINT
```

# Build

Using Makefile:

```bash
make
```

Manual build:

```bash
g++ \
src/main.cpp \
src/lexer/Lexer.cpp \
src/parser/Parser.cpp \
src/compiler/Compiler.cpp \
src/vm/VM.cpp \
src/tools/ASTPrinter.cpp \
src/tools/Disassembler.cpp \
-std=c++17 \
-o cvm
```

# Interactive REPL

Start REPL:

```bash

```

```text

Type 'exit' to quit.

>> x = 5;

>> print(x);
5

>> x = x + 10;

>> print(x);
15
```
