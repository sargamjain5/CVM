# CVM++

A custom stack-based programming language, bytecode compiler, and virtual machine built in C++.

CVM++ demonstrates the complete pipeline of language implementation:

```text
Source Code
    ↓
Lexer
    ↓
Parser
    ↓
Abstract Syntax Tree (AST)
    ↓
Bytecode Compiler
    ↓
Virtual Machine (VM)
    ↓
Program Execution
```

## Compiler Architecture

### Lexer

Converts source code into tokens.

Example:

```c
x = 10 + 20;
```

Tokens:

```text
IDENTIFIER(x)
ASSIGN
NUMBER(10)
PLUS
NUMBER(20)
SEMICOLON
```

---

### Parser

Builds an Abstract Syntax Tree (AST) from tokens.

Example:

```c
print(10 + 20);
```

AST:

```text
Print
 └── BinaryOp(+)
     ├── Number(10)
     └── Number(20)
```

---

### Bytecode Compiler

Compiles AST into custom bytecode instructions.

Example:

```text
PUSH 10
PUSH 20
ADD
PRINT
```

---

### Virtual Machine

Executes generated bytecode using a stack-based execution model.

Supported instructions:

```text
PUSH
LOAD
STORE

ADD
SUB
MUL
DIV

GT
LT
GTE
LTE

EQ
NEQ

JMP
JMP_IF_FALSE

PRINT
```

## Usage

### Execute a Script

```bash
./cvm examples/loops.cvm
```

---

### View AST

```bash
./cvm --ast examples/loops.cvm
```

Example Output:

```text
Program
  While
    BinaryOp(<)
      Variable(i)
      Number(5)
```

---

### View Bytecode

```bash
./cvm --bytecode examples/loops.cvm
```

Example Output:

```text
0 LOAD i
1 PUSH 5
2 LT
3 JMP_IF_FALSE 10
4 LOAD i
5 PRINT
...
```

---

### Interactive REPL

```bash
./cvm
```

Example:

```text
CVM++ REPL
Type 'exit' to quit.

>> x = 5

>> print(x);
5

>> x = x + 5;

>> print(x);
10
```
